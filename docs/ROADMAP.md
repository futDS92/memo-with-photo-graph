# Roadmap

## MVP

- 단어 추가
- 사진 첨부
- 뜻, 예문, 메모, 태그
- 관계 연결
- 맵 보기
- 검색
- 로컬 캐시
- 서버 저장

## v1.1

- 상세 편집 모달 개선
- soft delete와 복원 기능
- 사진 크롭/압축
- 최근 단어, 즐겨찾기, 태그별 보기
- 관계 자동 추천

## v1.2

- IndexedDB 도입
- 버전 기반 동기화
- 멀티디바이스 충돌 해결
- 그래프 배치 개선
- Web Worker로 레이아웃 계산 분리

## v2.0

- PostgreSQL + 오브젝트 스토리지
- 검색 엔진 도입
- 복습 스케줄링
- 공유 가능한 단어맵 링크
- 협업 단어장
