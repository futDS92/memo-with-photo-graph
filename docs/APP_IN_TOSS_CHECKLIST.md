# App in Toss Checklist

## 1. 구조

- 클라이언트가 AIT 앱 구조인지 확인
- `npx create-ait-app` 기반인지 확인
- 정적 HTML 배포가 아니라 `.ait` 빌드 산출물인지 확인
- `TDSMobileAITProvider` 또는 해당 프레임워크 설정이 들어갔는지 확인

## 2. 런타임 분리

- UI는 React + TypeScript로 구성되어 있는지 확인
- 상태는 IndexedDB 또는 동등한 로컬 저장소를 쓰는지 확인
- 서버는 저장/동기화 API만 담당하는지 확인
- `getTossAppVersion` 같은 버전 분기가 필요한 기능을 분리했는지 확인

## 3. 기능

- 단어 추가, 편집, 삭제가 동작하는지 확인
- 사진 첨부, 교체, 제거가 동작하는지 확인
- 관계 생성과 맵 반영이 맞는지 확인
- 검색, 필터, 상세 시트, 내보내기가 동작하는지 확인

## 4. 배포

- 앱 이름, 설명, 아이콘, 진입 경로가 일치하는지 확인
- 번들 크기가 제한을 넘지 않는지 확인
- 업로드 파일 타입과 용량 제한이 있는지 확인
- 네트워크 실패와 권한 거부에 대한 fallback UI가 있는지 확인

## 5. 운영

- 개인정보 저장 범위를 다시 확인
- 서버 저장 API 인증 여부를 확인
- 사진은 원본이 아니라 압축 또는 외부 스토리지로 분리하는지 확인
- 충돌 해결과 재동기화 기준이 문서화되어 있는지 확인
